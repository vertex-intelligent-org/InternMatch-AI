هذه مرحلة مطابقة للمكونات المشتركة ومعاينة الدخول والإنشاء. ليست إعلاناً عن اكتمال منصة الويب أو ربط الحسابات. تستكمل W1 محلياً دون تعديل الموبايل أو الباكيند أو التسويق أو إعدادات الإنتاج.

## الخط

المصدر `apps/mobile/src/theme/typography.js` يحدد الأحجام والأوزان والأسطر دون `fontFamily`. لا توجد ملفات TTF/OTF/WOFF في شجرة الموبايل التي روجعت، ولا يوجد تحميل خط مخصص في App.js.

نستخدم خط النظام: على أجهزة Apple يختار المتصفح خط النظام، وعلى Windows يستخدم Segoe UI عند توفره، وعلى Android يستخدم Roboto عند توفره. لا ندعي تطابق رسم الحروف بالبكسل بين Windows وiPhone؛ مقاييس التصميم والمبدأ موحدان. لا يوجد طلب خارجي إلى Google Fonts، وتبقى العربية نص Unicode حقيقياً قابلاً للتحديد والبحث.

## المكونات المنقولة

- الشعار: نفس هندسة الهدف 32×32 ونصف قطر 8.5 وأذرع العلامة؛ دوران واحد 800ms عند الظهور و750ms عند الضغط.
- PressableScale: ثوابت نابض الضغط الأصلية، مع مؤشر/لوحة مفاتيح وإلغاء الضغط عند فقدان التركيز أو مغادرة المؤشر.
- Reveal: ظهور 320ms، انتقال 8px ونابض المصدر؛ يبقى المحتوى مرئياً إذا لم تتوفر JavaScript/WAAPI.
- BrandedAILoader: هدف أصلي، دوران خطي 2400ms.
- AnimatedScoreRing: قطر 140، سماكة 12، حركة 850ms، وقيم محددة بين 0 و100 مع رفض NaN/Infinity.
- MatchIntelligenceOrb: حالات CV Needed/Ready/Calculating/Matched، الألوان المتدرجة الأصلية لكل ثيم، قطر 124/104، ونابض الظهور من 0.96.
- الزر الأساسي: solid color رغم اسمه الأصلي GradientButton؛ الأزرق الافتراضي ونصه حسب الثيم، ومؤشر النقاط 850ms.
- البار: طالب بخمس وجهات، وصاحب عمل بثلاث. الإطار 60px، العدسة 48px، الانحناء 30/24، ونابض العدسة 26/300/0.7. يتغمق اللون عند التمرير ويبقى معتماً؛ لا توجد طبقة native glass.
- أيقونات مسماة من Ionicons SVG v7.4.0 وفق أسماء الموبايل، مع الرخصة. علامات Google من مسارات SVG الموجودة فعلياً في SocialAuthButton. زر Apple هنا معاينة ويب وليس Apple native sheet.
- معاينة الدخول والإنشاء: التخطيط، الحقول، التبويبات، اختيار الدور، منع الحقول الأربعة قبل الدور، رسالة التركيز، Google/Apple ومعالجة أخطاء الحقول محلياً.

ملف `apps/web/src/theme/mobile-tokens.ts` يحفظ قيم ألوان/مسافات/خطوط/حركات المصدر كمرجع موحد. لا يتم استيراد Reanimated أو Expo أو وحدات الموبايل داخل Next.

قيم النابض الأصلية منقولة؛ التنفيذ يستخدم Web Animations API وعينات معادلة النابض. اختلاف محرك التصيير وnative gesture timing يجعل المطابقة الفيزيائية/البصرية أقرب من CSS ease عامة، لكنه ليس ادعاءً بتطابق native frame-by-frame. لا يوجد haptic أو صوت تلقائي في المتصفح. كل حركة تحترم prefers-reduced-motion.

## المسارات

| المسار | الحالة |
|---|---|
| `/app/foundation` | أساس W1 مع مقاييس الموبايل والشعار وروابط المراجعة |
| `/app/review/auth` | معاينة الدخول والإنشاء ببيانات تجريبية فقط |
| `/app/review/motion` | مكونات الحركة والخطوط والبار للطالب وصاحب العمل |
| `/app/sign-in` | حد الحساب الحالي؛ لا يسجل دخولاً ولا يجمع كلمة مرور |

معاينة `/review/auth` لا تُرسل طلباً، ولا تنشئ حساباً، ولا تحفظ حقول الهوية. أزرار المزودين تعرض بيان المعاينة فقط. اختيار دور المعاينة ليس تفويض صلاحيات. لا تستخدم معاينة الدخول كنقطة دخول إنتاجية.

## عدم إسقاط الوظائف

`mobile-screen-inventory.json` يحصر **28 تعريف Stack وست وجهات Tab** من المصدر الحالي، ويحدد الحالة والمرحلة لكل واحد. لا نسمي الصفحات غير المنفذة مكتملة. تبقى الاستعادة، تأكيد البريد، إنشاء الحساب، الملف، CV، المطابقة، التقديم، الخطابات، الحفظ، الحصص والخطط، الإشعارات، التحقق والامتثال، إدارة الفرص والمتقدمين، الحذف والموافقات ضمن النطاق.

الخطوة التالية W2: ربط جلسة الويب والمصادقة والتجديد والدور المرجعي عبر الباكيند، مع الحفاظ على عقود الحساب الموجودة وروابط الموبايل. بعدها تُنقل رحلات صاحب العمل والطالب. لا تغييرات في حسابات الإنتاج أو OAuth/CORS ضمن هذه الحزمة.

## التحقق

الحزمة تتضمن فحوص ترميز وقواميس ومصفوفة متصفح للغات والثيمين والأحجام، هندسة العدسة ومحاذاتها في RTL، الألوان المحسوبة قبل/بعد التمرير، مقاييس الخط، قفل الحقول، عدم إرسال POST، وتفضيلات تقليل الحركة. يُرفق سجل تحقق التنفيذ الفعلي مع الحزمة.

الأخضر في البناء لا يثبت اكتمال كل الصفحات أو التطابق البصري مع كل جهاز. يلزم لاحقاً اختبار Safari/Firefox وأجهزة فعلية ومقارنة صفحات كل رحلة مع الموبايل عند نقلها.
