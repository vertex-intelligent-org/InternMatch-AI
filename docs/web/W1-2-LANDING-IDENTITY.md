رُوجع مصدر اللاندينغ في `vertex-intelligent-org/InternMatch-AI-Marketing-Landing-Page`: `src/app/layout.tsx` و`src/app/globals.css` و`src/sections/Hero.tsx`. يحمّل المصدر Bricolage Grotesque وCairo، ويستخدم خلفية `#F7F7F5` وألوان العلامة `#467A8F` وإضاءة Aurora متعددة الألوان. استُلهمت منها خلفية ثابتة أخف للعمل الطويل، دون تكرار حركات الـhero خلف كل صفحة تشغيلية.

مرجع الحركة: `apps/mobile/src/components/motion/SplashBowArrowAnimation.js` و`src/screens/SplashScreen.js` عند `4ad7dc023ac09866b7b09e85c4f3d4ec8948d28b`.

قرار المستخدم الحالي يستبدل خط النظام في W1.1 بخط اللاندينغ للويب. الموبايل لم يُعدّل، وتبقى مقاييسه وحركاته مرجعاً حيث تناسب المتصفح.

## المنفذ

- Bricolage Grotesque للإنكليزية والتركية، وCairo للعربية، مع RTL الحالي.
- خمسة ملفات WOFF2 variable محلية: Latin/Latin Extended للخطين وArabic لخط Cairo. حروف التركية مغطاة بملف Latin Extended. نسختا OFL مرفقتان.
- المصدر المثبت للملفات: `@fontsource-variable/bricolage-grotesque@5.3.0` و`@fontsource-variable/cairo@5.3.0`. لم تُضف الحزمتان كاعتماديات للمشروع؛ نُقلت ملفات الخط المرخصة وCSS ذات الصلة فقط. لا طلبات Google Fonts وقت البناء أو تشغيل المنصة.
- canvas فاتح محايد، إضاءة لونية خفيفة، أسطح بيضاء واضحة. تبقى أسطح الداكن داكنة والبار الأزرق معتماً.
- إعادة تركيب معاينة foundation إلى ملخص صغير ومحتوى قائمة وإجراءات جانبية. أزيلت البطاقة الدعائية الكبيرة والزخرفة الدائرية ولوحة عينات الألوان من النظرة العامة.
- تبقى الأرقام والمحتويات بيانات توضيحية معلنة، دون API أو حسابات فعلية.

## القوس والسهم

يحافظ الرسم على هندسة القوس والسهم والهدف من الموبايل. تستخدم نسخة الانتظار تسلسل الموبايل نفسه مضغوطاً إلى 1.8 ثانية بدلاً من 3 ثوانٍ، حتى يمكن رؤية الجزء الأساسي خلال انتظار يقارب ثانيتين. إذا استمر الطلب، تدور علامة الهدف بهدوء بعد الحركة. عند تقليل الحركة يظهر الشعار ثابتاً بلا إطلاق أو دوران. لا صوت تلقائي.

الرسم SVG محلي، يتحرك عبر requestAnimationFrame ويتوقف عند إلغاء المكون. لا توجد مكتبة animation جديدة أو طلب خارجي.

- `app/loading.tsx`: fallback فعلي لتحميل segments في Next.js عندما يوجد انتظار. لا نجعل المسارات السريعة بطيئة لإظهار الحركة.
- `PendingRegion`: مكون للعمليات المستقبلية؛ قيمة pending تأتي من الطلب الحقيقي لدى المستدعي. لا توجد مدة انتظار دنيا.
- `BrandedWait`: يؤخر إظهار الحركة 250ms لتقليل الوميض، ولا يؤخر انتهاء الطلب أو التنقل.
- `/app/review/loading`: معاينة معلنة محلية لانتظار ثانيتين أو خمس ثوانٍ فقط. هذه المؤقتات داخل صفحة المعاينة، وليست تأخيراً لكل تنقل.

لم تُربط كل إجراءات الشبكة لأن رحلات المصادقة/البيانات لم تُنفذ بعد؛ ستستخدم المكونات عند ربط الطلبات الفعلية. لا يوجد ادعاء بأن foundation أصبحت منصة الإنتاج الكاملة.

## تدفق أزرار الموقع

بعد W2، يستخدم موقع التسويق روابط عادية إلى `/app/sign-in` و`/app/sign-up`، وتفتح الشاشة بالتبويب المناسب. إذا وجدت جلسة صالحة يظهر Continue to my account اعتماداً على التحقق الفعلي. لا نعتمد على علم محلي قديم لتحديد المصادقة.

في هذه الحزمة فقط، تدعم معاينة `/app/review/auth?mode=sign-up` فتح تبويب الإنشاء مباشرة؛ الوضع الافتراضي هو الدخول، والقيم غير المعروفة تعود إلى الدخول. لا تعديل في اللاندينغ المنشورة، ولا ربط OAuth أو Supabase أو إنشاء حسابات.

## حدود التحقق

فحوص المتصفح تشمل الخط المحمّل فعلياً عبر document.fonts، عدم وجود طلبات خارجية عند فتح foundation، الخلفية المحسوبة، عرض 320px، RTL، بقاء الداكن والبار، قفل الدور، سلوك الانتظار وانتهائه وتقليل الحركة، والوصول. فحص الحركة الثابتة عبر Axe يستخدم reduced-motion لتجنب قياس نص أثناء fade مؤقت؛ زمن الحركة وهندستها مفحوصان بشكل مستقل.

تظل مراجعة Safari/Firefox والأجهزة الفعلية من بوابة الإطلاق. لا commit أو push أو نشر أو تغيير للموبايل/الباكيند/قاعدة البيانات ضمن هذه الحزمة.
